에이전트 연결

Claude Code, Codex, 가재(OpenClaw) 같은 AI 에이전트가 이 노트를 읽고 쓸 수 있게 연결해요.

에이전트 토큰

토큰은 에이전트가 노트에 들어올 때 쓰는 열쇠예요. 에이전트마다 하나씩 만들어 주세요.

    권한

    새 토큰이 만들어졌어요

    이 창을 닫으면 다시 볼 수 없어요. 지금 복사해서 에이전트 설정에 붙여 넣으세요.

    자동 메모

    Claude Code와 Codex가 대화가 끝날 때마다 프로젝트(저장소)별 메모를 남겨요. 켜려면 터미널에서 npx https://notes.example.com/acard-cli.tgz hooks install

    불러오는 중…

    로그인으로 연결된 앱

    토큰 대신 로그인 창으로 연결한 앱이에요. 끊으면 그 앱은 다시 로그인해야 들어올 수 있어요.

      연결 방법

      쓰는 앱을 고르면 설정 방법이 나와요. 설정 속 <TOKEN> 자리에 위에서 만든 토큰을 넣어요.

      개인 지침에 붙여 넣을 한 줄

      쓰는 도구의 지침 자리에 붙여 넣으면 대화할 때마다 노트가 알아서 정리돼요.

      • Claude Desktop 설정 > 프로필(또는 프로젝트 지침)
      • ChatGPT 설정 > 개인 맞춤 설정 > 맞춤형 지침
      • Claude Code ~/.claude/CLAUDE.md (모든 프로젝트) 또는 프로젝트의 CLAUDE.md
      • Codex CLI ~/.codex/AGENTS.md (모든 프로젝트) 또는 프로젝트의 AGENTS.md
      • Codex 앱 설정 > 개인 맞춤 설정 > 맞춤 지침 (~/.codex/AGENTS.md 와 같은 파일이라 저장하면 그 파일을 덮어써요)

      다른 방법

      위 목록에 없는 앱이라면 이 주소를 직접 넣어요.
