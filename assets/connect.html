연결하기

주소 한 줄이면 에이전트가 이 노트에 작업을 기록해요. 처음 한 번만 브라우저에서 허락하면 돼요.

MCP 주소

이미 이 브라우저에서 로그인돼 있어서, 에이전트가 연결하면 허락 화면만 떠요.

개인 지침에 붙여 넣을 한 줄

쓰는 도구의 지침 자리에 붙여 넣으면 대화할 때마다 노트가 알아서 정리돼요.

  • Claude Desktop 설정 > 프로필(또는 프로젝트 지침)
  • ChatGPT 설정 > 개인 맞춤 설정 > 맞춤형 지침
  • Claude Code ~/.claude/CLAUDE.md (모든 프로젝트) 또는 프로젝트의 CLAUDE.md
  • Codex CLI ~/.codex/AGENTS.md (모든 프로젝트) 또는 프로젝트의 AGENTS.md
  • Codex 앱 설정 > 개인 맞춤 설정 > 맞춤 지침 (~/.codex/AGENTS.md 와 같은 파일이라 저장하면 그 파일을 덮어써요)

Claude Code · Codex 자동 기록 (훅)

훅을 설치하면 모델이 까먹어도 대화가 끝날 때마다 질문과 답이 작업 기록에 남아요. <TOKEN> 자리에 설정 > 에이전트 연결에서 만든 토큰을 넣으세요.

    끄려면 같은 명령에서 install 을 uninstall 로 바꿔 실행하세요. Codex 는 처음 한 번 /hooks 에서 새 훅을 신뢰해야 돌아가요. CLI·데스크톱 앱·IDE 확장이 같은 설정 파일을 쓰니 한 번만 설치하면 돼요.
